# Cisco ACL Network Security

## Project Overview

This portfolio project documents Cisco Networking Academy exercises involving Access Control Lists (ACLs) and network traffic filtering using Cisco Packet Tracer.

The purpose of these exercises is to develop practical knowledge of how routers control network traffic, enforce access restrictions, and help protect network resources.

## Tools and Technologies

- Cisco Packet Tracer
- Cisco IOS Command-Line Interface (CLI)
- IPv4 and IPv6 Networking
- Access Control Lists (ACLs)
- Network Connectivity Testing

## Lab Topics

### 1. Standard IPv4 ACLs
Explore how standard access control lists filter traffic based on source IPv4 addresses.

### 2. Named and Numbered ACLs
Practice using named and numbered access control lists to organize traffic-filtering rules.

### 3. Extended IPv4 ACLs
Explore how extended access control lists filter network traffic using source and destination addresses, protocols, and ports.

### 4. ACL Security and Attack Mitigation
Examine how access control policies can restrict unauthorized network traffic.

### 5. IPv6 ACLs
Explore access control concepts and traffic filtering in IPv6 environments.

## Important Cisco Commands

| Command | Purpose |
|---|---|
| `enable` | Enter privileged EXEC mode |
| `configure terminal` | Enter global configuration mode |
| `access-list` | Define a numbered ACL entry |
| `ip access-list standard` | Create or edit a named standard IPv4 ACL |
| `ip access-list extended` | Create or edit a named extended IPv4 ACL |
| `ip access-group` | Apply an IPv4 ACL to an interface |
| `show access-lists` | Display configured ACL entries |
| `show ip interface` | Verify interface ACL assignments |
| `ping` | Test network connectivity |
| `show running-config` | Review the active device configuration |
